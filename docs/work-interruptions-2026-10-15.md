## Порядок продолжения

1. Сначала сохранять код и результаты проверки в удалённой draft-ветке.
2. Перед возобновлением сверять PR head, локальный tree и записанный прогресс загрузки; не повторять успешно завершённые шаги вслепую.
3. Переносить файлы небольшими порциями, проверять SHA, сохранять результат каждого завершённого шага на диск.
4. После полного совпадения дерева пройти CI, слить PR и проверить публикацию по SHA. Не выдавать локальный успех тестов за успешную публикацию.
5. Production Supabase, секреты, клиентские данные и реальные тестовые заявки не менять этим выпуском.
